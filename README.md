# RelayIQ – Smart Delivery Optimization System

RelayIQ is an AI-based delivery optimization system designed for Zomathon.

## Features
- A* route optimization
- Greedy delivery agent selection
- Kitchen preparation time prediction
- Relay-based delivery system
- Delivery analytics visualization

## Technologies
Python  
Pandas  
NumPy  
Matplotlib  
Scikit-learn
